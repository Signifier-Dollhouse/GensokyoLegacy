# Reimu Quest Dialog — 中文拟议对话

> 以下为英文审阅稿中“Suggested lines”的中文本地化拟议版本。结构、任务目标、数量、解锁顺序与奖励均不作修改；固定的每日任务按钮与共享台词也保持不变。

## Greeting

- 菜单问候：**“嗨！来神社有什么事？”**
- 交易标题：**“我想和你交易！”**

## 7.1 `local_food` — Shrine Provisions

### START
- 按钮：**“聊聊食物。”**
- 灵梦：**“我还在摸索这个世界什么东西能吃。带些面包和蘑菇煲来，让我了解一下这里的食物吧。”**
- 拒绝：**“在陌生世界里采集食物，可没写进巫女的手册。不过，我大概也能自己应付。”**
- 接受：**“好。面包和蘑菇煲。没什么讲究，先让这个巫女填饱肚子再说。”**

### FOLLOW-UP
- 按钮：**“问问食物。”**
- 灵梦：**“食物找得怎么样了？”**
- 接受进行中：**“我一直看着村民吃东西，自己却只能干看着。”**

### COMPLETE
- 按钮：**“交出食物。”**
- 灵梦：**“回来了啊。希望你带来的是食物，不是又一笔捐款。”**
- 拒绝：**“不急。我就继续做做蘑菇煲的白日梦吧。”**
- 交付：**“啊，终于有真正的食物了。谢谢。你是我来到这里后第一个能指望上的人。”**

## 7.2 `hostile_loot` — Hostile Analysis

### START
- 按钮：**“主动提出猎取样本。”**
- 灵梦：**“那些行尸和咔嗒作响的骷髅老是来偷袭我。它们不算真正的妖怪，但我想研究一下。带些腐肉和骨头回来吧。”**
- 拒绝：**“确实有点危险。不过你在这里活得比我久。准备好了再去也行。”**
- 接受：**“好。两种各十只，再带些腐肉和骨头回来。够我研究就行。”**

### FOLLOW-UP
- 按钮：**“问问狩猎。”**
- 灵梦：**“猎得怎么样了？”**
- 接受进行中：**“样本找到了吗？腐肉和骨头应该能告诉我不少东西。”**

### COMPLETE
- 按钮：**“交出样本。”**
- 灵梦：**“回来了。希望你没变成它们的一员。”**
- 拒绝：**“不急。只是别让它们啃到你。”**
- 交付：**“很好。现在我可以拿这些和我熟悉的妖怪比较了。辛苦你跑这一趟。”**

## 7.3 `talisman_materials` — Talisman Materials

### START
- 按钮：**“聊聊符札。”**
- 灵梦：**“这里的纸很好折，这种红石粉又会发光，还充满力量。我可以拿它当朱砂墨，做出这个世界的符札。带些来吧。”**
- 拒绝：**“它是红的，会发光，而且充满力量。拿来当朱砂墨已经够好了。”**
- 接受：**“好。纸用来折，红石用来当墨。这样神社的库存就够了。”**

### FOLLOW-UP
- 按钮：**“问问符札。”**
- 灵梦：**“材料找齐了吗？”**
- 接受进行中：**“我想看看这些新符札到底好不好用。”**

### COMPLETE
- 按钮：**“交出材料。”**
- 灵梦：**“带来了啊。让我看看。”**
- 拒绝：**“好啦，好啦。符札可以再等等。”**
- 交付：**“很好。现在可以做新的符札了。也给你做几张。”**

## 7.4 `ominous_banner` — Raider's Banner

### START
- 按钮：**“聊聊掠夺者。”**
- 灵梦：**“大家一直在说*掠夺者*——一群带着黑白旗帜的武装家伙。带一面他们首领的旗子给我。我想看看那上面到底是什么意思。”**
- 拒绝：**“说到底也只是拿着武器的人类。准备好对付他们以后再来吧。”**
- 接受：**“好。他们的首领会带着那种不祥旗帜。解决掉一个，把旗子带回来。不过要小心，他们会留下一个不祥的印记。”**

### FOLLOW-UP
- 按钮：**“问问旗帜。”**
- 灵梦：**“找到他们的首领了吗？”**
- 接受进行中：**“去看看前哨站和巡逻队。你最有可能在那里找到他们。”**

### COMPLETE
- 按钮：**“交出旗帜。”**
- 灵梦：**“就是这个。让我看看这面怪旗子到底在说什么。”**
- 拒绝：**“慢慢来。我会在这里等着。”**
- 交付：**“就是它。我会研究这群掠夺者到底靠什么联系在一起。然后再想想该怎么收拾他们。”**

## 7.5 `raid` — Repel the Raid

### START
- 按钮：**“聊聊计划。”**
- 灵梦：**“我弄明白那个印记了。我的符札可以重新做出它。我把印记放到你身上；你进村，把掠夺者引出来，再把他们赶走。”**
- 拒绝：**“我还有神社的事要做。你更了解这个世界，所以战斗就交给你了。”**
- 接受：**“好了。印记已经在你身上了。进村把他们引出来，然后把所有掠夺者都赶走。”**

### FOLLOW-UP
- 按钮：**“问问袭击。”**
- 灵梦：**“村子还撑得住吗？”**
- 接受进行中：**“他们会一波一波地来。守住阵线。”**

### COMPLETE
- 按钮：**“告诉灵梦袭击结束了。”**
- 灵梦：**“那些一波波的家伙停下来了？很好。看来计划成功了。”**
- 拒绝：**“还没结束？那就保持警惕。他们没那么容易放弃。”**
- 交付：**“你把他们全赶走了。我就知道把他们引进村子会有用。给——拿着我的*梦想天生*符卡。”**

## 7.6 每日任务

### `daily_food`

- 固定按钮：**“我可以帮你收集。”**
- 拒绝：**“也许晚点吧。”**
- 接受：**“我来做！”**
- 跟进按钮：**“进展怎么样？”**
- 进行中：**“我还在做。”**
- 完成按钮：**“东西都拿来了！”**
- 共享接话：**“哦，你拿来了？让我看看！”**

唯一台词：
- 开始：**“捐款箱又空了，而且我也饿了。带几样神社用得上的东西来吧。”**
- 接受：**“很好。带一批像样的回来。”**
- 拒绝：**“饿着肚子的巫女可没精神干活。随你。”**
- 跟进：**“东西收集得怎么样了？”**
- 进行中：**“不急。记得带些有用的回来。”**
- 完成：**“正好是神社需要的。谢了。”**

### `daily_talisman`

固定按钮与共享接话同上。

唯一台词：
- 开始：**“符札库存又快见底了。纸和红石，还是之前那些。”**
- 接受：**“很好。补好库存，我就能继续给神社做结界。”**
- 拒绝：**“没库存就没法做结界。随你。”**
- 跟进：**“纸和红石找到了吗？”**
- 进行中：**“符札架子都快空了。”**
- 完成：**“很好。架子又补满了。”**

### `daily_hunt`

固定按钮与共享接话同上。

唯一台词：
- 开始：**“神社附近最近总有东西惹麻烦。把那些怪物清掉，再带些战利品回来。”**
- 接受：**“很好。去把它们清干净。”**
- 拒绝：**“它们只会越来越嚣张。不过随你。”**
- 跟进：**“打得怎么样了？”**
- 进行中：**“在外面小心点。我可需要你完完整整地回来。”**
- 完成：**“又能让大家安稳睡一晚了。谢了。”**

### `daily_raid`

固定按钮与共享接话同上。

唯一台词：
- 开始：**“新的印记准备好了，又有一个村子需要保护。准备再来一次袭击战吗？”**
- 接受：**“给你印记，和上次一样。进村、守住阵线，把他们赶出去。”**
- 拒绝：**“印记会留着。等你准备好，掠夺者还在那里。”**
- 跟进：**“村子还撑得住吗？”**
- 进行中：**“他们会一波波地来。别松懈。”**
- 完成：**“村子还好好的。看来你已经很熟练了。”**

## 本地化注意事项

- 保留“印记”作为 3.1 → 3.2 → daily_raid 的连续概念。
- 2.2 中保持“纸 + 红石 → 朱砂墨 → 符札”的逻辑。
- 3.1 不提前解释 3.2 中如何利用印记。
- 不把灵梦写成学者型角色；她应该是直接、实际、自信。
- 避免依赖英语双关、俚语或文化特定笑话，以便后续本地化。
